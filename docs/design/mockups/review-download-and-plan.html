The prototype page downloads less

The three fonts were embedded in the stylesheet as text, so the phone had to load 703 kB before it could draw anything, and again after every deploy. They are now compressed font files of their own, the same fonts with no letters changed. Unused engine-test data also left the script. Measured from the production build:

FileBeforeAfter
Stylesheet703 kB (344 gzipped)6 kB (2 gzipped)
Fonts, three filesinside the stylesheet222 kB, kept between visits
Script435 kB (129 gzipped)402 kB (126 gzipped)

A first visit transfers about 475 kB before and about 350 kB after, so 26% less (gzipped totals, estimate). The bigger gain is that text draws at once in the fallback face, and later visits reuse the cached fonts. Most of the script that remains is React (about 190 kB); shrinking it means a different library, which would need your approval (SAFE-03). In a browser at iPhone size all three fonts loaded and the founding screen looked as before. All 261 tests pass.
