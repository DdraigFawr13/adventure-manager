Tools and skills review

What helps build Adventure Manager faster, cheaper or safer, and what doesn't. Measured numbers come from this repo today; anything else is judgement. Source: docs/design/TOOLS-REVIEW.md.

Your two questions

Useful, already in use

Ripgrep

Installed, and Claude Code's own search is built on it. Speed doesn't matter at this size (10 searches: grep 27 ms, ripgrep 62 ms).

The saving is searching instead of reading: the decision index costs ≈1,100 tokens against ≈10,900 to read DECISIONS whole (10× cheaper); a topic search ≈500 (22×). It matters more once code and node_modules exist, which it skips.

Not adopted

Caveman skill

Makes Claude write in clipped English to cut output tokens: claimed 75%, tested 15–25%.

But output is only 0.6–2.5% of a session's tokens; the bill drops about 1–3%. It would also make explanations harder to follow. Shorter sessions save far more (see the audit).

Setup audit: two findings for you

The setup-audit skill ran on this repo (report only). The setup is clean: one hook, 19 read-only allow rules, nothing risky, cache hit ratio 99.3%.

  • Start a fresh session per merged PR or plan sectionYour callThis one session has re-read 58.2 million cached tokens (measured). Cached reads cost a tenth of normal input, but at this size they dominate. A new session starts near the 84k-token baseline and resumes from HANDOFF. No setting needed, just a habit.
  • Add a few deny rulesYour callThe project settings have 19 allow and 0 deny rules. Deny reading .env files and secrets/, and deny force-push, before keys and code arrive. Low risk today.
  • 84 skills listed in every sessionParkedAbout 7,500 tokens (estimated), many unrelated (data, Canva, plugin management). Optional to turn off unused plugins in your claude.ai settings.
