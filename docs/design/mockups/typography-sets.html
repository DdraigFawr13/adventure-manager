Guild type sets

Style Q5, third pass: flair in every font, not only titles, and the decorated initial stays. Each set gives titles the most character, letters a medium amount and ledgers a light touch, so a 14 px roster still scans. Where a font’s digits are uneven widths, the numbers come from a matching font with equal-width digits so columns line up. All faces are SIL Open Font License.

Rule for any choice: the strongest flair goes on titles and seals, a lighter touch on letters and ledgers. Numbers always use equal-width digits so columns line up. Names, figures and text are placeholders.
