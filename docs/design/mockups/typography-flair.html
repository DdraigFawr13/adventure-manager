Guild type flourishes

Style Q5, second pass: you chose the Alegreya family and asked for more whimsy, medieval and fantasy. Reading text and ledgers stay Alegreya and Alegreya Sans (now 14 px). Only the titles, the illuminated initial on letters and the ornaments change. All faces are SIL Open Font License.

Rule for any choice: the display face is for titles, names on seals and set pieces only. Ledgers, numbers and buttons use the data face with tabular figures, so columns line up. Names, figures and text are placeholders.
