Reading the ledgers

Corrected 26 Oct: the first version of this page showed the old-press ledger with its default old-style figures, which rise and fall and vary in width. The face also has lining figures (all on the line, equal width), which the game will use for numbers. All specimens now use them.

Text options for dense screens (PLAN §6c). Every specimen is shown at its real pixel size, as on a 1080p monitor at 100% scaling: a roster ledger and the opening of a letter. Titles stay in the old-press face (STYLE §5) in every option.

A · Text size only

The old-press faces everywhere (as locked), with a size slider from 100% to 150%. Readability problems are solved by making things bigger.

GoodOne look for everyone; no second set of fonts to test.
CostAt 150% a dense screen shows about a third fewer rows, so players who need it scroll more. The old-press roughness stays (the risk noted in STYLE §5).

B · Size slider plus "clear print" Recommended

As A, plus a clear-print setting that swaps ledgers and letters to a modern book serif. Titles, seals and the decorated initial keep the old-press look, so the game still looks like itself.

C · B plus a high-legibility face

As B, plus a third choice built for low vision and reading difficulties. It is the most readable and the least in period.
