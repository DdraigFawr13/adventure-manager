Review findings and what was done

  1. MajorUsing a pack item could blank the page: the old pick was still shown for one render and asked for an item that had left the pack. Fixed: a pick now belongs to the move it was made on, previews only reach valid targets, and an error screen keeps the save aside and offers a new fight. Reproduced first: the old screen fails the new firebomb step in the check script; the fixed one passes.
  2. MajorThe turn-order tests checked only the first step of knockback, Haste and raised allies, and several skill edges had no test. Fixed: 10 new tests play two rounds for knockback, Haste on an ally who already acted, and an ally raised after their place passed; plus Cleave with one foe, Guard's use and its end when the warrior falls, Tactics, Spark and Ward never stacking, Firebolt and use counts.
  3. MinorAn event held the foes' intents by reference. Fixed: copied value by value.
  4. MinorThe round's marks cleared without an event. Fixed: a round.ended event.
  5. MinorThe save test wrote the save itself, so it couldn't catch a page that stopped saving. Fixed: the page and the test both go through one commit that plays and saves.
  6. MinorA save with a damaged fight was loaded, and if an unreadable save couldn't be copied aside it could be overwritten. Fixed: the fight is checked on load, and the page plays without saving when the copy fails.
  7. MinorThe screen guessed "heal" or "never misses" from numbers (a rule in the UI). Fixed: the engine's preview now says what the action does.
  8. MinorThe preview test checked only the dice and swallowed every error. Fixed: it compares the whole state and accepts only the expected errors.
  9. MinorThe reload check compared two characters. Fixed: it compares the round, the turn strip and every health line.
  10. MinorThe delve spec didn't say Spark, knockback and Hamstring apply only on a hit. Fixed in delve/SPEC.md.
  11. MinorA misplaced comment in the boundary check. Fixed.
  12. MinorA member who started a fight Down would never get a turn once raised (a slice 2 trap). Fixed: every living member keeps a place in the order.
