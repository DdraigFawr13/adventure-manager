The kingdom map

A first workshop for the launch goal (D-087): a map of the March that shows its areas and places, the guilds, what is happening now, and the deeds done there. Year 4, autumn, in a save where The Lantern Company was founded at Wendle. Every name and mark is an example. Use the switches to compare the two base styles and to turn each layer on and off.

How the base map is made

A · Hand-illustrated

An artist draws the whole March: washes, coasts, a compass rose, a sea serpent, the title cartouche. The live layers sit on top.

Most beautiful and distinctive. One fixed region; generated regions later (D-030) would each need new art.

B · Procedural ink

Code draws the map from region data using an artist's stamp set (woods, hills, fen marks, towns). The same renderer draws the quest-board sites.

Cheaper and works for generated regions. Flatter; risks looking generated, which works against the "cool fantasy" goal.

C · Hand base now, procedural later Recommended

The launch region gets the hand-illustrated base (A). The live layers, and later generated regions, use the procedural ink renderer (B), which is built anyway for the quest board.

Launch looks its best; the generated-region mode still has a path. Cost: the illustrated map (~$3,000–10,000, estimate) plus the stamp set already counted for sites.

What each layer shows

  • Areas and places. Biomes, the 8 settlements and landmarks; zoom from kingdom to county.
  • Factions. Who holds sway where (heraldic colours, D-048); shifts as the region changes.
  • Guilds. Banners at each guildhall with ranking tier; yours stands out.
  • Action. Parties as standees moving on routes, rivals' too; a seal marks a waiting key moment.
  • Threats. Spreading ink stains; sharper with better knowledge (D-083 rule 5); closed roads.
  • Rumours. The clerk's pencil notes; they become contract leads (D-043).
  • Deeds. Inked cartouches that stay on the map: beasts slain, defences held, the fallen with a mourning corner. Over a long save the map becomes the guild's history (Pillar 3).
  • Everything links to its Trace (D-082): click a stain, banner or deed to see why it is there.
