Guild icon styles

Style Q6: how icons look. The same ten icons in four treatments, at card size (64 px), button size (24 px) and ledger size (16 px), then in a ledger row. The shapes are rough stand-ins I drew to show each treatment; an artist draws the real set. Judge the 16 px row hardest: that is where icons live most of the time.

Icons never carry meaning alone: status icons always sit beside a word or a colour-blind-safe status colour (D-048). Whatever the style, the small-size version can ship as the custom symbol font from D-052 so icons sit inline with text. Names and figures are placeholders.
