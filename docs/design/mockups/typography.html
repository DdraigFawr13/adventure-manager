Guild type specimens

Style Q5: the typefaces. Each sheet does the three jobs the game asks of type: a title, an in-world letter you read for flavour, and a dense ledger at 13 px that you scan for hours. Judge the ledger hardest. All faces are under the SIL Open Font License, so they can ship in a commercial game.

Rule for any choice: the display face is for titles, names on seals and set pieces only. Ledgers, numbers and buttons use the data face with tabular figures, so columns line up. Names, figures and text are placeholders.
